# CLIMB MASTER

Мобильный 3D-платформер с физической механикой подъёма на Godot 4.3.

## Текущая сборка
- Android: landscape, ARM64 debug APK.
- Камера: боковой вид с плавным следованием за игроком.
- Персонаж: человек в металлическом котле.
- Инструмент: управляемый пальцем серп; упор в поверхность передаёт реакцию на котёл.
- Маршрут: чередующиеся левые и правые уступы, фотограмметрические валуны, каменные и металлические препятствия.
- Контрольные точки, высотомер, рекорд, пауза и сброс.

## Управление
1. Коснись игровой области.
2. Не отпуская палец, веди его по экрану — серп поворачивается вслед за пальцем.
3. Упрись серпом в камень или уступ и продолжай вести палец, чтобы оттолкнуть котёл вверх или в сторону.
4. Если упал, нажми ↻ для возврата к последней контрольной точке.

Кнопки паузы и сброса расположены в правом верхнем углу. Отдельных кнопок движения и прыжка нет.

## Проект
Открой корневую папку проекта в Godot 4.3. Главная сцена: `scenes/main.tscn`.
Скрипты: `scripts/main.gd`, `scripts/player.gd`.
Модели и текстуры: `assets/models/`.

## Editor plugins
- Phantom Camera 0.9.3 is included and enabled for Godot 4.3 editor workflows on the `plugin-integration` branch. Runtime camera migration is intentionally separate until the current follow camera is regression-tested.

## Android APK
GitHub Actions запускает сборку при push в `main` или вручную через вкладку Actions → Android Debug APK → Run workflow.
Артефакт называется `CLIMB-MASTER-Android-debug`.

## Ограничения текущего прототипа
Сборка APK проверяет импорт проекта и экспорт, но не заменяет тестирование касаний, физики, посадки персонажа и производительности на реальном Android-устройстве. Небо пока процедурное, с палитрой заката; фотографическая панорама не подключена.
