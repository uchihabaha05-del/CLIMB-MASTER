# CLIMB MASTER — мобильный прототип

Ранний 3D-прототип на Godot 4 для Android и iOS.

## Что уже есть
- 3D-сцена с последовательностью платформ.
- Персонаж в металлическом котле и молот.
- Базовая физика движения и попытка зацепа молотом.
- Камера, следующая за персонажем.
- Высотомер и экранные кнопки.
- Сброс после падения.

## Управление
- Перетаскивай палец по игровому экрану, чтобы направить молот.
- Отпусти палец, чтобы выполнить попытку зацепа.
- Кнопки внизу двигают персонажа.
- Кнопка ↻ возвращает персонажа на старт.

## Открытие
Проект создан для Godot 4.3. Открой папку проекта в Godot Editor. Для сборки Android потребуются Godot export templates, Android SDK и JDK. Для iOS потребуется macOS с Xcode и подпись приложения.

## Текущий статус
Это прототип механики, а не готовая игра. Физика зацепа, управление на сенсорном экране, визуальные модели и экспорт требуют проверки и дальнейшей разработки.
